# Effets sonores locaux (optionnel)

Déposez ici un WAV nommé d'après un son du moteur pour remplacer sa version
synthétisée : `pop.wav`, `pencil.wav`, `whoosh.wav`, `transition.wav`,
`click.wav`, `marker.wav`, `writing.wav`, `impact.wav`, `notification.wav`,
`success.wav`, `subtle_hit.wav`, `riser.wav`, `exit.wav`.

Un fichier présent ici est prioritaire sur le son synthétisé.

**La licence des fichiers déposés ici vous incombe.** Documentez-la dans
`docs/SFX_LICENSES.md`. Par défaut ce dossier est vide et CutForge n'utilise
que des sons qu'il calcule lui-même — donc rien à licencier.
